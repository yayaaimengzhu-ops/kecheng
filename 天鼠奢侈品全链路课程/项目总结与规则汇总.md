## 二、课程设计上的决定

1. **讲法用 5:3:2**：为什么（48%）、证明（31%）、怎么做（21%）。
2. **坑放进“为什么”**：先讲不能怎么做，最后再教正确方法；坑和讲点合并讲，不单列。
3. **起步方式是先做回收**：小额起步、不囤货、不先租店。经营模式按 C2B → B2C → C2C 往上走；B2B 不当主业，同行和上游是补货和兜底资源。
4. **报价**：线上只给区间，线下按城市给准确价。
5. **兜底**：靠同行资源群、靠谱上游、群里求助、找我们（不收钱）；不建议只固定一个兜底。
6. **30 天陪跑不在课里**，课后只有咨询服务，期限定为 1 年。
7. **合规加微的方法**从原 5 天课内容里提取。
8. **线下演练**要包括碰到真客户时怎么回答。
9. **结营要埋后端**。
10. **核心公式**：单件毛利 × 周转次数 = 一年赚多少。不用“客单价 × 周转率 = 现金流”，那个式子不成立。

- **其他渠道**：转介绍、门店客户、免费公开课优先；同行群、短视频、本地圈子其次；付费投流最后。

## 五、规则汇总

### 1. 宣传合规（对外内容一律适用）

| 规则 | 适用范围 |
| --- | --- |
| 不说“暴富、稳赚、月入多少”，不承诺收益 | 广告、海报、直播、朋友圈 |
| 抖音标题、贴片不用“回收”字样 | 抖音视频标题、直播间 |
| 不在直播间口播或展示微信号、二维码、手机号 | 所有直播平台 |
| 直播间直接挂课程链接需要平台对应类目资质；没有就只种草、不挂链接 | 直播间 |
| 划线“原价”必须过去真实按这个价成交过，否则算虚构原价 | 详情页、海报 |
| 不用“半拼音半汉字”之类绕开平台审核的写法 | 所有平台 |
| 课件不写容易被理解成拉关系的说法（如“体制内”“上层建筑”） | 课件、录屏 |
| 平台规则常变，每次开播或投放前，由运营再核对一遍 | 直播、投流 |

### 2. 对外承诺口径（说了就要做到）

- 课后服务统一说“1 年课后咨询服务”，不说“陪跑”。
- 判不准的真实货，发给我们看，不收费。
- 开课前一周发预习资料和 10 题小测。
- 每期 20 人，坐满不加位。

- 先结论后展开，一页 PPT 只讲一件事。
- 不编造数据；行业数字讲课前换成有出处的最新数据，并说出来源。
- 缺的信息标“待补”或留空，不自己编；不需要写的内容整块删除，不留占位。
