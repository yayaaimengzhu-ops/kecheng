直播间内容体系
短视频获客 · 五层纵深

把之前三份（提问清单、空场选题、诊断框架）合成一套。每一层都自带三件事：怎么问、独播讲什么、用什么实物演。以后开播只要选一层，三个动作全在里面。

主线是一句话：怎么用短视频，让有货要出的人主动来找你。

替代 提问清单 · 空场选题 · 诊断框架
结构 五层 × 三动作
排期 一周五场，一场一层
生死线

不讲"怎么做短视频"，只讲"怎么让有货的人来找你"。

"怎么做短视频"是通用赛道——黄金三秒、完播率、封面标题，谁都能讲，而且讲得比你好的人有的是。你一进这个赛道，就变成了几千个短视频老师里的一个。

"怎么让有货的人来找你"是你独有的。因为这行的难点根本不在拍摄剪辑，在于你拍的东西吸来的是不是卖家。

通用短视频课解决的是"播放怎么起来"。二奢的真问题是——播放起来了也没用，来的全是想卖包的消费者和看热闹的，不是要出货的人。这句判断只有真在收货的人说得出来。

地图

五层纵深入口统一，往下扎到链路

只讲短视频，三个月就讲干了——那些知识点是有限的，网上还遍地都是。所以入口统一在短视频，纵深往链路里扎：短视频做不起来，一半的问题根本不在短视频上。

层核心判断诊断切口实物载体
L1 认知播放不等于客户。你吸来的是看客不是卖家你评论区问什么的最多两条视频的数据对比
L2 选题钱是钩子，真假是过程你标题里出现过价格吗一件货拍出五个选题
L3 呈现你手上有真货，别人只能讲理论你拍货拍几个镜头现场拍给他们看
L4 承接短视频只负责把人带来，断在哪跟它没关系你聊到哪一步断的聊天记录打码复盘
L5 底层不敢报价、出不掉货，内容就没底气你上一单是什么时候压最久的那件货
L5 是转化层。观众冲着"学短视频"进来，听到这一层才发现自己真正卡的在别处——而那个别处，正好是你课里讲的。所以每一层最后都要往 L5 带一句，不要只停在本层。
L1

认知层为什么你的短视频吸不来卖家

核心判断

你追的是播放，你要的是客户。这是两件事，而且经常是反着的。

诊断怎么问 连麦时

  1. 你拍了多久了？一周几条？
  2. 你最好的一条播放多少？
  3. 那条视频给你带来几个加微信的？播放和私信一对比，问题当场显形
  4. 你评论区里，问什么的最多——问真假的，还是问能卖多少的？这一问定生死
  5. 私信来的人，有几个是真有货的？
  6. 你觉得看你视频的人，是什么人？拿他的自诊，八成是错的

独播讲什么 没人连麦时

  1. 播放几万，私信为零，你少做了一步
  2. 你的视频吸来的是卖家，还是看客
  3. 为什么鉴定教学拍得越好，客户越少
  4. 一条五百播放的视频给我带来三个客户，一条五万播放的一个没有
  5. 我从来不追播放，我追的是私信里有几个真有货的
  6. 评论区问"这个真的假的"的人，永远不会卖货给你
  7. 粉丝多不等于生意好，我认识几个反例
  8. 你的账号在给谁打标签，你自己知道吗

实物怎么演

  • 调出自己两条视频的后台，一条高播放一条低播放，对比带来的私信数
  • 翻自己的评论区，念几条出来，指出哪类人是客户哪类不是
收口钩子"我整理了一张表，二奢账号最常犯的十个错，你对一遍就知道自己在哪一条。扣『自查』。"
L2

选题层拍什么才能让有货的人来找你

核心判断

钱是钩子，真假是过程。客户不关心怎么鉴定，只关心自己那件能卖多少。

诊断怎么问

  1. 你最近十条拍的是什么？让他一条条说，别让他概括
  2. 你的标题里出现过价格吗？八成没有
  3. 你拍的内容是让人学会，还是让人想卖？
  4. 你有固定的选题库吗，还是想到什么拍什么？
  5. 你拍完之后，会看评论区来的是什么人吗？
  6. 你写选题的时候，想过这条视频的人怎么找到你吗？引出钩子承接

独播讲什么

  1. 同一条内容，标题换一个词，来的人完全不一样最该反复讲的一条
  2. 二奢最出量的五类选题
  3. 为什么"差价"是这行最好的钩子
  4. 客户故事为什么比干货管用
  5. 真假对比怎么拍才有人问价
  6. 写选题的时候就要把导流路径写完
  7. 我的一百条选题是怎么攒出来的
  8. 爆款改编：一个选题怎么变成十条
  9. 什么选题千万别碰，会把号带偏
  10. 选题大于表现力，我举个例子

实物怎么演

  • 拿一件货，现场拆出五个不同的选题。同一只包，可以拍真假、拍差价、拍成色、拍客户故事、拍避坑——演给他们看选题是怎么来的
  • 把同一条内容的两个标题写在白板上，让观众投票哪个会来卖家
收口钩子"一百条选题库，每条后面带钩子怎么接，我发给你。扣『选题』。"
L3

呈现层怎么拍 · 你最大的优势在这一层

别的短视频老师手上没有真货，只能讲理论。你手上有，就能演。这一层也是空场最好撑时间的一层——手上有活干，情绪自然在。

核心判断

拍货和拍脸是两回事。不出镜完全能做，但货必须拍出信任感。

诊断怎么问

  1. 你拍一件货，拍几个镜头？
  2. 你出镜吗？不出镜的话拍什么？
  3. 一条视频你拍几遍？拍十遍以上的人，坚持不下去
  4. 你有固定的拍摄流程吗，还是每次现想？
  5. 你的设备一共花了多少钱？花太多和花太少都是问题

独播讲什么

  1. 这只包我今天要拍条视频，我给你看我会怎么拍最标准的一个单元
  2. 同一只包，这么拍没人看，这么拍有人问价
  3. 我拍货固定拍这五个镜头
  4. 不敢出镜怎么办，四种做法
  5. 找人出镜怎么谈、怎么分工、协议要写什么
  6. 现场收货怎么拍，客户隐私怎么处理
  7. 我的设备一共花了多少钱，哪几件是必须的
  8. 布光差一点，成片差多少——我现场调给你看
  9. 一次拍十条的流程，我怎么安排
  10. 前三秒到底该放什么
  11. 为什么你的货拍出来显得廉价

实物怎么演 这一层全程演示

  • 现场架机位拍一条，边拍边讲
  • 同一只包用两种打光拍，画面摆一起对比
  • 把设备一件件拿出来，讲各自解决什么问题
  • 现场演示手部出镜怎么拍，不露脸也能有信任感
收口钩子"拍摄流程和设备清单，我写成一页纸了。扣『怎么拍』。"
L4

承接层人来了怎么接住

核心判断

短视频只负责把人带来。人来了断在哪，跟短视频一点关系都没有——但大部分人会怪短视频。

诊断怎么问

  1. 有人在评论区问了，你怎么引导的？
  2. 加微信的申请话术是什么？让他念原话
  3. 通过之后你第一句说什么？这一问最见功力
  4. 你朋友圈发吗？发什么？多久一条？
  5. 你一般聊到哪一步断的——问诊、要图、还是报价？
  6. 客户不肯发图的时候你怎么办？
  7. 你要图的时候，会告诉他拍哪几处吗？八成人没做过这一步

独播讲什么

  1. 评论区一堆人问，就是没人加微信
  2. 通过好友第一句话，八成人说错了
  3. 四种钩子，哪种吸精准卖家，哪种只吸白嫖党
  4. 加了三百人一单没成，卡在哪一步
  5. 客户不肯发图，是你没教他怎么拍
  6. 客户发的图看不清，怎么指挥他重拍
  7. 朋友圈发成微商被屏蔽，改这四类内容
  8. 为什么第一次聊绝对不能报价
  9. 客户说"我再考虑一下"，其实是什么意思
  10. 怎么判断这个客户是不是真想卖
  11. 跟进节奏：当天、三天、七天、三十天各说什么

实物怎么演

  • 翻自己的聊天记录（打码），复盘一单从加微信到成交的完整过程
  • 现场演示"指挥客户拍图"——拿一件货，讲该拍哪几处、怎么跟客户说
收口钩子"各品类要客户拍哪几张图，我做成清单了。扣『要图』。"
L5

底层你的内容为什么没底气 · 转化层

这一层是整套体系的落点。观众冲着学短视频来，在这一层才发现自己真正卡的在别处——而那个别处正好是你课里讲的。每一场都要往这一层带一句。

核心判断

短视频做不起来，一半的问题不在短视频上。你不敢报价，所以内容里不敢碰价格；你出不掉货，所以不敢收；你不敢收，所以拍出来的东西没底气。

诊断怎么问

  1. 你敢在视频里说价格吗？为什么不敢？这一问是整套诊断的枢纽
  2. 你收进来的货，出得掉吗？
  3. 你现在压着多少件？最久的压了多久？
  4. 你判不准的时候怎么办——放走，还是有别的路？
  5. 你报价的依据是什么？有行情表吗？
  6. 你上一单是什么时候？收网一问

独播讲什么

  1. 你为什么不敢在视频里说价格最该反复讲的一条
  2. 短视频做不起来，一半问题不在短视频上
  3. 压着货的人拍不出好视频，为什么
  4. 不会鉴定能不能做？三条路绕开它
  5. 收了出不掉，你的内容会越来越虚
  6. 收之前必须回答的三个问题
  7. 判不准的时候，除了放走还有四条路
  8. 账面上你没亏，为什么手上没钱
  9. 什么时候你不该做短视频最能立人设的一条
  10. 我认识几个人，一条视频没拍过，做得比谁都好
  11. 你手上那三百个好友，比三个月的视频值钱

实物怎么演

  • 把压在手上最久的那件货拿出来，现场算账：收多少、压多久、这笔钱本来能翻几轮
  • 翻出行情表给他们看，讲一个价是怎么算出来的
收口钩子"渠道对照表 + 收之前三问的卡片，扣『渠道』。想知道自己该不该做短视频的，扣『盘点』，我把资源盘点表发你。"
"盘点"这个钩子是整套体系里最值钱的一个。资源盘点表填完，对方自己就知道该不该做短视频、该走哪条路——而且你拿到了他的完整资源画像，私信跟进时直接有话说。
动作

三个动作怎么统一提问 · 给答案 · 独播

提问：从本层问起，必须往下扎一层

  • 开场三连固定不变：你在做还是准备做 → 你最头疼什么 → 你觉得问题出在哪
  • 按他的答案落到某一层，问那一层的问题
  • 但一定要往下扎到 L4 和 L5。问到"加了微信之后你聊到哪一步断的""你报价的依据是什么"——这两问一出来，观众就知道你不是只懂短视频的人
  • 提问六技：重复数字停一下 · 复述确认 · 二选一逼选不许绕 · 推翻自诊 · 排比反问 · 问全场

给答案：硬结论 + 小动作

  • 收网三句："行，我大概明白了" → "你以为你的问题是 A，其实是 B" → "你回去改一件事就够了"
  • 动作必须是今天就能做的。"把标题里的真假换成钱"能做；"你要建立获客体系"做不了
  • 结论软了立不住人设，动作大了他回去做不了
  • 问到八到十二个问题就收网。对方重复自己、连说两次"不知道"、某个数字明显不对劲，任一出现立刻停

独播：本层选题 + 实物演示 + 猜价破冷场

  • 每层的独播选题走完整痛点结构：你有病 → 找病因 → 我有药 → 三不吃
  • 没人打字就抛猜价，这是唯一能让陌生人主动打字的低门槛动作
  • 问了没人答就顺势接："行，没人说，那我说说我看到的情况"——冷场变内容
  • 状态靠"事"带不靠"演"：手上一直有活干，语气自然有劲

口径

必须处理的预期落差每场都要说的一句话

直播间只讲短视频获客，来的人预期买的是"短视频课"。到时候卖全链路课，落差会很明显——"我是来学拍视频的，你怎么让我买这个"。

所以在直播间就要不断说一句话，每场至少一次：

固定口径

短视频只是入口。你真正卡的地方，八成不在这。

这既是真话，也是为课程铺垫，而且正好是你课程的核心主张——手上有什么资源就 all in 哪条路，短视频不是唯一的路。

直播间的一句话主张

教你用短视频找到卖家，
也告诉你什么时候不该用短视频。

后半句是钩子，也是护城河。当着直播间劝人别做短视频的人，只有你一个。——这句话建议直接做进贴片和账号简介，视觉层定的时候用得上。
