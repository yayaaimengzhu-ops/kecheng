二手奢侈品回收 · 全链路实战课

v6 精简版。五天，一天一个主题，一天交一样东西。v5 的业务主线不动（定位 → 获客 → 成交 → 鉴定 → 出货），内容砍掉大半；短视频和私域两块整段换成短视频密训里跑通过的做法。

核心主张

手上有什么牌，就先打什么牌。

短视频是主流入口，但不是唯一的路；不会鉴定也能开始，因为有人兜底；先学不亏钱，再学多赚钱。

第一节

这门课给谁

只收三类人。招生页、直播间、开课第一天都用下面三段话分人，每个人进教室前知道自己这五天重点听哪几天。

A 类

做过别的生意，还没进二奢

手上有：会经营，有人脉和老客户，有一点启动资金，有的有门店。

缺：不知道这行怎么赚钱，分不清真假，不知道货往哪卖。

重点听：D1 起步模式、D3 老客户激活、D4 兜底体系。

别先租店囤货。先用老关系跑出第一单，鉴定先找人兜底。

B 类

做过回收：寄卖行、二手车、二手数码、二手号

手上有：回收流程、估价习惯、门店和本地客户、地推和本地推经验、登记存证意识。

缺：品类真假、二奢的出货渠道、二奢客户要的人设和信任。

重点听：D3 老客户交叉转化、D4 鉴定与兜底、D5 二奢出货渠道。

你的流程能直接搬，老习惯（线上报高、线下压价）在二奢会把信任打没。

C 类

做过二奢，没做起来

手上有：账号、一些客户、一些货、踩过的坑。

缺：找到自己卡在哪一步。没客户、压货、不敢报价、号的标签乱了，解法各不相同。

重点听：D1 六个数找卡点、D2 账号重做、D5 压货自救。

多数人不是不努力，是在一个废号、一批压着的货上硬撑。

不收的人，招生时就说清：只想学鉴定的（去技术课）；想知道自己那只包真不真的消费者；想听完就有人帮着做的。这门课五天里一半时间在练，回去 30 天每周要交作业。
第二节

三条原则

  1. 按牌选路。先盘清手上的牌，选一条主路跑出第一单。第一个月八成时间压在这一条上，另外几条不是不碰，是排在后面。
  2. 先避损，再赚钱。判不了的找人兜底；收之前先想好从哪出、几天出、到手多少。风控不单独开课，每天讲完收尾三条红线。
  3. 一天交一样东西。听懂不算，交出来才算。每天晚上交作业，第二天早上点评。
第三节

五天一张图

沿着一单生意走：先定怎么起步，再把人找来、聊熟，然后看货、出价、收进来、卖出去。深色两天是这门课和别人拉开差距的地方。

D1入行定位这行怎么赚钱，你从哪种模式起步，每天做多少事交：一页起步方案 D2短视频获客拍什么、怎么拍，发出去让有货的人来找你交：账号五件套 + 一条成片 D3私域成交 · 线下获客人从哪进微信，进来以后怎么聊到肯发图交：激活名单 + 标签分级 D4鉴定避损什么自己判，什么找人判，出事第一小时做什么交：兜底清单 + 动线卡 D5估价出货 · 结营从一件货到回到账上的钱，再到客户回头交：渠道表 + 30 天计划
每天怎么上：早上 20 分钟点评前一晚作业（挑三份投屏批注）→ 上午讲和演，每讲一块放一个真实案例，做一组判断题 → 下午分组练 → 收尾 15 分钟讲作业。讲师只讲方法，数字和案例用自己的真实经历。
第四节

课前：只做三件事

  1. 把四类底牌预填成数字：能直接打电话的人有几个、老客户名单有多少人、有没有门店和每天进店人数、能拿出来亏掉不影响生活的钱是多少。
  2. 截图现有的账号（没有就写"没有"）：粉丝数、最近三条的播放和私信数。
  3. 手上有货的带 1–3 件来，D4 盲测用自己的货练。来源说不清的别带。

v5 的课前风险自测十题保留为选做，结营不再强制前后对比。

D1

入行定位

解决三件事：这行到底怎么赚钱；你该从哪种模式起步；想赚多少，每天要做多少事。

时间环节讲什么 · 练什么
09:00–09:30开营签到；五天地图；每个人用一句话说"我是 A / B / C 类，我想从这门课拿走什么"。
09:30–10:40这行怎么赚钱一条货流：卖家 → 回收 → 同行 / 平台 / 寄卖 → 买家。
你卖的是服务，赚的是信息差和周转，像房产中介。压货是在赌行情，那是另一门生意。
六个误解逐条拆：不会鉴定就不能干；必须自己出镜；必须有店有钱；短视频是唯一的路；收得越多赚得越多；风控是做大以后的事。
10:50–12:00盘底牌四类底牌：人脉和老客户 · 门店和本地资源 · 线上账号 · 时间和钱。
形容词换数字："我人脉广"换成"能直接打电话不尴尬的有 23 个，其中家里有闲置包表的大概 8 个"。两人一组互相追问，拿不到数字不放过。
13:30–14:30起步模式撮合（先找好买家再收）· 寄卖（不压钱赚佣金）· 回收（压钱赚差价），新人先从前两种起步。
安全通道三阶段：只做撮合和有票的低价货 → 单笔有上限的自收 → 放开品类和金额。
当场写止损线：单笔最多亏多少；连续几单看走眼就停下复盘。
14:40–15:40算账一单毛利全口径（扣物流、鉴定费、平台佣金、退货损耗）；看走眼一单要白干几单；周转比毛利重要。
月目标倒推每天动作：想赚多少 → 几单 → 谈几个客户 → 加几个微信 → 每天拍几条或打几个电话。
15:50–17:00选主路线上一条：短视频（D2）。线下两条：老关系、本地门店（D3）。付费投放和闲鱼是加速器，不当主路。
每人当众说一句："我走 X，因为我手上有 Y，第一个月每天做 Z。"说不出来的回去重盘底牌。
C 类加一项：用六个数（加微数、开口数、报价数、成交数、毛利、周转天数）找出掉得最狠的一环。
A 类六个误解和起步模式是你最该听的。先撮合寄卖，不租店不囤货。你的主路大概率是老关系。
B 类重点听二奢和原行业的四处不同：真假风险在你身上；出货渠道不一样；客单价高一个数量级；客户更在意隐私和信任。
C 类六个数找卡点。卡在加微就重点听 D2，卡在聊天就听 D3，卡在压货就听 D5。
今天的三条红线
  1. 把形容词当资源，all in 一条其实不存在的路。
  2. 先租店、装修、囤货，再去找客户。
  3. 没写止损线就开始收货。
当晚交 · 一页起步方案四类底牌（数字）· 起步模式 · 主路 · 每天动作量 · 止损线。结营时拿回来重填一次。

移出正课：经营主体、税务、三本账、合伙协议进资料包"经营底座一页纸"；v5 的九类风险地图不再单讲，红线分到每天。

D2

短视频获客

解决：拍什么、怎么拍、发出去怎么让手里有货的人来找你。今天的视频拍给消费者看——手里有闲置想出手的人、想买二奢的人，不拍给同行看。

时间环节讲什么 · 练什么
09:00–09:40底层逻辑成交三角（工具卡 2-1）；流量看选题，跟时长、发布时间、两秒跳出关系不大；账号标签由粉丝是谁决定，刷同行视频打不了标签。
09:40–10:30账号五件套现场改：真人头像；带人味的昵称（"X 哥 / X 姐"加业务）；简介写从业年限、实力、服务特色、价值观；背景图放实力，不和简介重复；置顶三条（个人故事 · 我怎么对客户 · 服务流程）。
10:40–12:00选题人群只有一个（见下）；什么不是选题；三个素材库；四类脚本各管什么（2-2）；用八大爆款元素现场改选题（2-3）。
13:30–14:30知识干货脚本新号先拍这类。六小类：避坑 · 省钱 · 谈资 · 内幕 · 行业黑话 · 解决问题。呈现形式按点数选（2-4），现场写一条。
14:30–15:20vlog 脚本起号后拍，转化最好。交易、挑战、盲盒、工作、日常五种；六脉神剑结构；选题看人、事、货。
15:30–16:10人设人设四象限；故事＝事件＋感悟；观点站消费者那边；情绪当下就录（2-6）。
16:10–16:40开篇五类句式，否定句最强（2-5）。拿上午写的脚本改开头。
16:40–17:20拍和发记词、情绪、构图；标题话题写给搜索看；违规怎么查怎么申诉；抖加只在一种情况投（2-7）。
工具卡 2-1 · 成交三角：流量 + 人设 + 产品
少了哪样会怎样
少流量专业、价格都不错，就是没人知道你。
少人设来的人只比价，几家差不多就砍价。你信任的人报价，你不会跟他讲价。
少产品有人看、有人信，但不知道你做什么。你的产品是服务：上门、打款快、帮客户卖高。

每条脚本写完、整个账号搭完，都拿这三样对一遍，至少占一到两样。

人群只有一个：手里有闲置想出手的人，或者想买二奢的人。不要写"25–35 岁一线城市女性"——这群人里大多数不买奢侈品。给 AI 出选题时也这样写人群。
什么不是选题："我做奢侈品回收"是赛道；"想清这批库存"是目的；"花 3 万买到假 LV"是标题；"开箱、口播"是形式。选题是具体讲的那件事，比如"上门去客户家收了几只包"。
三个素材库：手机备忘录、语音笔记（得到大脑 / get 笔记）、抖音收藏夹。分六个夹子：选题 · 开篇 · 呈现形式 · 结构 · 金句 · 客户常问的问题。刷到好的就收，写稿时翻。行业内抄知识，行业外抄结构。
工具卡 2-2 · 四类脚本，各管一件事
类型管什么什么时候拍选题举例
知识干货流量、涨粉、把标签打准新号前 2–4 周主拍去二奢店买包，第一句别问"能不能专柜验货"
vlog 记录展示服务，带转化起号以后客户说十点前赶不到就不卖了，我们三个半小时飞过去
故事人设和信任每 1–2 周一条，全程穿插置顶的个人经历；一个客户连找我五次的事
观点情绪让同频的人站到你这边同上背假包的成本，比背真包高

只做一类卖不动：只讲内幕的号能火但成交不了。一开始就拍人设故事，来的人很杂，标签会偏。

工具卡 2-3 · 八大爆款元素：把普通选题改成想看的选题
元素怎么用普通 → 改后
成本必须有具体的钱或时间我们收包很快 → 挑战一小时收完 50 只包
人群点名一类具体的人推荐几款上班背的包 → 月薪五千的 95 后，第一只大牌包怎么选
奇葩站在消费者角度出乎意料收了一只成色差的包 → 客户把 LV 扔进洗衣机洗完拿来卖
最差要说到极致这几款包不建议买 → 八大品牌最不保值的包
反差同一维度对比这款包很保值 → 同款迪奥，我挂三天就出，隔壁挂了三个月
怀旧老款、老一辈客户拿来一块旧表 → 老父亲留下的上海牌手表
荷尔蒙男女之间的吸引，慎用这包适合约会 → 第一次去高档餐厅，背这只就够
头牌明星同款、顶级品牌店里新到几只包 → 盘点明星同款，我店里有三只

回收类选题把钱拔高、时间压紧；卖货类选题把预算压低。所有选题站在客户有利的那一边。

选题避雷
  • 别把鉴定教学当选题：吸来的是同行和想白嫖鉴定的人。真假只拿来证明你懂。
  • 别揭自己行业的利润，别讲"开一家店要多少钱"：消费者听完只会更不信你。
  • 别拍段子、别炫富：来的是看热闹的，账号标签会乱。
  • 敢讲买卖二奢的坑。你讲了，客户会觉得你不会坑他。
工具卡 2-4 · 呈现形式：按要讲几个点来选
点数形式结构和拍法
3 点以内内心 OS提问 → "我要不要告诉他" → 方法 → "算了算了，我不告诉他"。先录好音，拍的时候认真听录音，神态自然。
3 点以内偷窥视角有遮挡物或低机位，和人对话、不对镜头。结构："我不要 A，因为……不要 B……不要 C……"
3 点以内口播痛点 → 方法 → 引导；或反常识、揭秘冲突、清单盘点。
5 点以上打枪一图一句。人从画面一侧走进来说完走出去，不要坐着念；头顶打标题。
5 点以上一人分饰两角一左一右、一问一答；同一机位先把一侧说完，再换机位，剪的时候拼。
记录类vlog 六脉神剑起因钩子 → 见到客户 → 为什么卖或买 → 报价 → 客户反应 → 收没收。选题看人（沪漂女孩）、事（一波三折调货）、货（一柜子爱马仕），没有狠货就拼人和事。表现力弱的先拍口播，vlog 写好脚本再演。
工具卡 2-5 · 开篇五类句式
类型句式例
好奇花 X 钱买到 Y 是什么体验 / 如何不……也能……如何不攒半年工资，也能背上一线大牌
痛点不知道……你一定会亏 / 别再……了不知道回收渠道的差价，你至少少拿三成
利益没想到……就能…… / 教你用 X 的价格拿下 Y教你用轻奢的预算拿下一线大牌
借势XX 都在…… / 在……之后我发现做了五年回收我发现，大多数人卖包都亏在同一个地方
恐吓千万不要……否则…… / 如果你再不……千万别用湿纸巾擦老花，擦一次就回不去了

否定句比肯定句强，肯定句比疑问句强："这款包千万别买" > "这款包可以买" > "这款包能买吗"。
选题用八大元素改，开头用这五类句式改，两件事分开做。

工具卡 2-6 · 人设
  • 人设四象限：公开的越多，别人越信你；隐私挑能说的说，拿一个小秘密换一份信任；别人指出的毛病就改；多试没做过的事。没有完美的人设，只有完整的人设。
  • 红线：可以润色，不能编。普通店老板别包装成专家，刚学完鉴定别说自己做了十年。
  • 故事＝事件＋当下的感悟。没有感悟就是流水账。个人经历按"钩子 → 背景 → 低谷 → 转折 → 现在"讲；用画面感（"紧张到手心发紫"）和对比（"从 50 平做到 300 平"）。北方方言可以用，南方方言少用。
  • 观点：一条视频只站一边，永远站消费者，不替商家和品牌说话；给他想做的事找个理由。
  • 情绪：当下有情绪就拿手机录，随手拍比摆拍好。
工具卡 2-7 · 拍和发
记不住词提词器，一句一行，读错就重来；身边人念一句你说一句；531 练法：5 分钟随便讲 → 按结构改稿 → 3 分钟再讲 → 1 分钟脱稿录。
情绪上不来开口前加语气词或称呼（"哈哈""唉""我跟你说"），后期剪掉；每天对镜头录 5–10 分钟。
构图眼睛放在画面上三分之一那条线，人别居中。
标题和话题写给搜索看：城市或商圈 ＋ 事件 ＋ 品牌；话题加自己的 IP 词。"回收"二字不写。搜索来的人转化远高于推荐来的。
定位做本地就定本地，想跑全国就不加定位。发布时间不用挑。
违规三处查：作品"数据分析"里的作品状态、消息通知、创作者中心的"账号检测"。能申诉就申诉（让 AI 写，200 字内，别骂人）；申诉不过就隐藏，改掉违规点再发。处理掉不影响别的视频。
抖加只在一种情况投：自然流 24 小时过 1 万播放。内容加热 → 点赞评论 → 自定义 24 小时 → 100 元 → 保证播放量 → 智能投放。小额多次。不过 1 万的不投，投了来的是老年粉，标签会偏。
换号翻拍几条爆过的知识类还是起不来，说明标签已经乱了，换号比硬扳快。

标"讲师实测"的平台规则会变，每期开课前核一遍。

发布节奏：新号前 2–4 周主拍知识干货，翻拍爆过的选题，先把标签打准 → 起号后加 vlog 和推荐类带转化 → 全程每 1–2 周穿插一条故事或观点，一个月不少于 4 条。
今天不讲：剪辑技法（找人剪，或进短视频密训）；设备清单（一部手机加一盏补光灯够了）；多平台同时做（先只做抖音，小红书不投流很难起）；矩阵号；AI 数字人。
A 类你的跨行经历本身就是好故事："做了十年餐饮，转行收包"。置顶第一条就拍它。
B 类你最该拍 vlog：上门、验货、打款你本来就熟，拍出来就是信任。人设可以用"做了 X 年二手车回收的人怎么看二奢"。
C 类先判断号还能不能用：翻拍几条爆过的知识类，起不来就换号。以前拍鉴定教学的，停掉。
今天的三条红线
  1. 标题文案写"回收""最高价""保真"，视频里说"来找我估价"。
  2. 私信或评论区主动发联系方式，图片、语音、谐音都算。
  3. 视频里给的价和收货时给的价对不上。公开估价只给区间和前提。
当晚交账号五件套截图 · 10 个选题（标出类型和用了哪个爆款元素）· 1 条拍好的成片（不要求发布）。主路是线下的人，选题可以少交五个，成片照交。
D3

私域成交 · 线下获客

解决：人从哪进你的微信，进来以后怎么聊到他肯把货和图拿出来。不管人从短视频来、老客户来还是门店来，最后都进你的微信。账号会封、平台会变，微信里的人是你带得走的。

时间环节讲什么 · 练什么
09:00–09:20为什么做私域平台和行业都会变，微信里的客户换了平台、换了品类也还在；一千个精准好友，每年哪怕只有 5% 回来成交一次，就是一盘稳定的生意。
09:20–10:40线下和老关系获客A、B 类的主场。老客户分层激活、原行业客户交叉问一句、门店、异业、地推、转介绍（3-1）。两个加速器各讲 5 分钟。
10:50–11:30线上引流合规联系方式放哪、私信怎么回、钩子用什么（3-2）。
11:30–12:00加微后 30 分钟第一句话送资料破冰，不发"亲爱的欢迎"加九宫格。当场给三个真实好友发破冰消息。
13:30–14:20标签和分级标签字段、四种身份、SABC 四级（3-3）。现场给 20 个已有好友打完标签。
14:20–15:10朋友圈信任存折、七类内容、排版（3-4）。现场改自己最近十条。
15:20–16:00私聊按标签推、五个触发点、死单激活（3-5）。
16:00–17:10问诊和要图两人一组对练，录像回放：先问后报、图没齐不给数字、各品类要图清单、来源异常信号（3-6）。不涉及报价，专练把人聊开。
工具卡 3-1 · 线下和老关系：人从哪来，值不值
渠道怎么做算账口径
通讯录、老客户分三层：能直接打电话的 / 说得上话的 / 只加过微信的。朋友圈先铺垫两周，再分批开口，不群发。几乎零成本，第一单最快
原行业老客户B 类专用。卖过车、手机，寄卖过东西的人，家里多半有闲置包表。回访时加一句"家里有不用的包表，也可以拿来帮你看看"。同上
门店门头加一块"奢侈品寄卖 / 回收"；地图、点评认领；进店先加微信，不管成不成。已有客流，只差一句话
异业先谈三类：金店典当、修表洗护、美容医美。送一次养护清洗，换一个微信。分成写进协议。本地推一条电话 200–300 元，还都是比价的；异业换来的更精准
地推、沙龙、集市免费养护、行情小讲座。花 500 元换来 5 个本地微信就值
转介绍成交后开口，送 50–100 元的小礼物，奖励只给直接介绍人。成功率最高的一条

两个加速器（各一页纸）：付费投放，承接和成交没跑通前不投；闲鱼，发求购帖，只走平台流程，不跟"买家"去站外。

工具卡 3-2 · 线上引流合规
  • 联系方式只放平台允许的位置（个人号简介、合集说明、企业号自带的联系方式），以开课当期规则为准。
  • 私信里不聊业务，不主动发联系方式；让对方自己留，蓝 V 用官方留资组件。回收报白的号别在私信里聊卖货。
  • 钩子用资料：行情表、买包避坑清单、各品类要图清单。视频里不说"来找我估价"，那会判引流。
  • 个人微信每天加人不超过 30 个，新号 10 个左右。客资多了就慢慢加。
工具卡 3-3 · 加微后：破冰、标签、分级

破冰：✗ "亲爱的欢迎加我，我们专营包包腕表首饰……" ＋ 九宫格产品图
✓ "我整理了一份买包避坑清单（或：这个月的行情表），发你一份？"——先给东西，他回了，话就接上了。加好友 30 分钟内发出第一条，隔半天他就忘了你是谁。

标签字段：来源（记到哪条路：短视频 / 老客户 / 门店 / 异业）· 想买还是想卖 · 品牌偏好 · 预算 · 禁忌。
四种身份：买家 · 卖家 · 同行 · 羊毛党（羊毛党不用花力气）。

级别参考（按自己店的客单改）怎么维护
S年消费 10 万以上一对一，带称呼或发语音；新货先给他看；生日节日问候，寄小礼物；行情大动时单独说。
A3–10 万主动私聊 ＋ 定向可见的朋友圈。
B有消费能力、频率低朋友圈触达，每月或每季度私发一次。
C很少消费批量管理，每月 1–2 次活动消息。

不建群。二奢客户在意隐私，同行会潜进来截胡，在群里发货也显得廉价。朋友圈加一对一就够了。

工具卡 3-4 · 朋友圈
  • 头像、昵称、简介和短视频账号保持一致。客户加进来，第一件事是翻你的朋友圈。
  • 信任存折：科普、日常、互动是往里存，广告和产品是往外取。产品少发，生活多发。
  • 七类内容：人设日常 · 产品 · 客户反馈（买家秀、好评截图，先打码）· 科普 · 互动（猜价）· 稀缺 · 反向种草（"这只好看，但不一定适合你"）。
  • 排版：首行 20 字以内；配图 1–3 张，不发九宫格；别堆表情符号，一看就是 AI 写的。一天 2–5 条。
  • 不写"保真""全网最高价"，不编成交和好评。
工具卡 3-5 · 私聊
  • 按标签推：买爱马仕的别推 LV 新货。不一键群发，不用"在吗"开头。
  • 五个触发点：到了他要的货 · 他给你点了赞 · 节日和生日 · 行情变了 · 店里有活动。活动要真给到实惠。
  • 大约一个月一次；S 级可以勤一点，但每次都要有事说。
  • 死单激活用真实行情说话，不编"下周就跌"。客户明确拒绝就停。
工具卡 3-6 · 问诊和要图
  • 前三十秒做三件事：问品类、要图、约好什么时候给价。没看到货不报数。
  • 图没齐，给时间不给数字："这几张补给我，今天几点前给你一个准价。"
  • 按各品类要图清单要：包、表、金银珠宝各拍哪几张。客户拍不好，是你没教他怎么拍。
  • 以图搜图查盗图；高价件请对方带一张手写日期一起拍。
  • 来源异常信号：急着出手、对价格不敏感、说不清怎么来的、不愿登记。记进标签，成交前复核。听出对方未成年，立刻停。
A 类今天是你的主场。你最值钱的是老客户名单，先激活它，再考虑拍视频。
B 类门店加一块业务、老客户回访加一句话，是你第一个月最快的单。原行业"线上报高、线下压"的习惯今天就改。
C 类把加过但没成交的人全部打标签分级，按触发点重新聊一轮。这是你最便宜的客源。
今天的三条红线
  1. 一键群发，朋友圈天天硬广刷屏。
  2. 没看到货就报死价；私信里说"保证这个价""肯定收"。
  3. 客户的身份证、住址存在相册里随手转发。私域号挂在员工名下。
当晚交老客户分层激活名单（不少于 30 人）· 标签分级截图（不少于 20 人）· 一包真实客户图（不少于 3 件货，D4 第一轮盲测用）。
D4

鉴定避损

目标不是成为鉴定师，是不亏。一件货摆在面前，知道什么自己判、什么找人判、出了事第一小时做什么。这一天对不会鉴定的 A、B 类最关键。

时间环节讲什么 · 练什么
09:00–09:40三道防线结构性规避（撮合、寄卖、验后付）· 借力判定（上游、机构、同行、平台）· 自己判（L1 一眼假 / L2 常见款 / L3 边界）。用 D1 的测算表算：看走眼一单要白干几单。
09:40–10:40兜底体系上游怎么找、怎么开口、让多少利润换兜底；鉴定机构对照；同行复核不暴露客户；决策表（下表）。
10:50–12:00判定动线固定顺序看，不靠灵感。五个通用维度：工艺、材质、五金、字体钢印、气味手感。30 秒一眼假。非真假问题：翻新、改色、换件、拼装、后加钻，比假货更常见。
13:30–15:30分品类轮转按学员主打品类分组，包 / 表 / 金钻珠宝各 40 分钟：先发动线卡，再上实物。
15:40–16:40盲测四轮① 用 D3 要来的客户图判一轮，图不全的当场暴露 ② 实物盲测 ③ 30 秒排除 ④ 20 个场景走决策表——第四轮是考核点：知不知道什么时候不该自己判。
16:40–17:20讲给客户听只说"不收"或"无法确认"，讲清依据，不替客户下"假货"定论；验完当场封签、拍特征点，防交割时调包；收到假货后第一小时：封存货品、固定聊天和付款记录、暂停同一来源的交易。
工具卡 4-1 · 这件货该怎么处理
情况处理
低价、常见款、自己主打品类、有票有卡自己判，直接收
高价、疑难款、客户有争议、下游要报告送机构，鉴定费算进成本
大货、不熟的品类、客户急着出找上游兜底，让出一部分利润
常见款但把握不足、时间来得及找同行复核（图里去掉客户信息）
完全没把握，或超过自己的单笔上限转撮合，不碰货权

这张表也放进招生页："不会鉴定也能开始，因为你有五种处理方式。"

A 类你的主路是借力。课后第一周先谈下 1 个上游和 1 家机构，比学十个品牌的细节有用。
B 类你的登记存证习惯能直接用。但二奢没有统一检测标准，真假风险在你身上，别按车和手机的思路收。
C 类回头查一遍手上压着的货：有没有改色、换件的货，按原品价收进来的。
今天的三条红线
  1. 判不了硬判，怕丢单、怕显得不专业。
  2. 只凭一个特征下结论：芯片、日期码、小票、全套配件都能造。
  3. 验完不封签，货离开视线再交割。
当晚交兜底清单（1 个上游、2 个复核同行、1 家机构，写名字和联系人）· 自己主打品类的动线卡（修订版）· 盲测四轮记录。

移出正课：服饰、鞋、数码、文玩等其他品类进资料包；疑难件、全品类深度、鉴定服务变现属于技术课（L3 之后），课上说清边界。

D5

估价出货 · 结营

解决：一件确认过的货，报多少、怎么安全收进来、从哪卖出去、钱怎么回来、客户怎么再来。收和出放在一天讲：收的那一刻，这单赚不赚已经定了。

时间环节讲什么 · 练什么
09:00–09:30出货预判三问走哪个渠道出 · 几天能出掉 · 扣完手续费和物流到手多少。答不上来就不收。三问写在白板上，一天不擦。
09:30–10:20出口先行同行和上游（最快、价最低）· 寄卖平台 · 得物 · 直播间寄卖 · 自己零售（最高、最慢）。同一件货在不同渠道到手价对比。直播卖货只当出货渠道，不当主业。
10:30–11:30估价看成交价，不看挂价；成色、配件、瑕疵各折多少；好出的让利抢，难出的必须压；从到手价倒推报价上限。二十件真货每人盲报一轮。
11:30–12:10报价和议价线上给区间和条件，见了货按实物逐处讲清折价。五个高频场景对练："你报得太低""别家更高""我再想想""能不能先寄给你""你是不是骗子"。
13:30–14:30成交流程验货 → 出货预判 → 报价 → 确认 → 来源核查、身份登记、全程录像 → 签回收单 → 付款 → 交付。必拒清单；上门两人同行、出发前报备；异地先收货验完再付款。回收单和寄卖协议当场填。
14:30–15:10压货与周转周转天数怎么算；滞销预警线；已经压了怎么办：定出货截止日、降一档走同行、换渠道、转撮合。
15:20–15:50复购成交后 48 小时回访；什么时候开口要转介绍；每周看六个数，掉得最狠的那环回到对应那天的资料。
16:00–17:00结营重填 D1 的起步方案：知道了鉴定和出货难度以后，品类和主路还选它吗？写 30 天计划。讲师按每个人的方案说清他接下来三个月最该补什么，不在现场搞促销。
报价口径统一 线上给区间和前提，见了货按实物讲清每一处折价。不要线上报高把人骗来再往下砍——在二奢这就是投诉和差评，也和短视频里"敢讲坑，客户才信你"的路子自相矛盾。
A 类第一单走撮合或寄卖，或者直接走兜底上游的渠道，不压钱。
B 类你的出货渠道要重建：二手车、数码的下家不收包表。今天至少加上 3 个真实的二奢出货联系人。
C 类今天的重点是压货自救：给每件压着的货定一个出货截止日，到期降一档走同行。
今天的三条红线
  1. 不登记、不录像、不签单就付款；先付款后验货，尤其异地。
  2. 只看转账截图就发货，没见到钱先发货。
  3. 真假存疑的货包装成正品卖；瑕疵、翻新、换件不写明。
结营交渠道对照表（至少 3 个真实出货联系人）· 收货流程卡（含必拒清单）· 30 天计划。

移出正课：三本账、发票和税务、员工内控与员工协议、团队复制、门店装修陈列，进资料包或后端课。

第七节

前后怎么接：直播 → 三晚课 → 五天 → 后端
